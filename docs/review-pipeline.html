RFA 기밀 검토 흐름

밖으로 나가는 글은 세 가지를 거친다. 어디로 나가는지는 샌드박스가 강제하고, 무엇이 나가는지는 코드와 검열 에이전트가 검사하고, 마지막은 사람이 정한다. 사람의 결정은 목록으로 쌓여 다음 검사에 쓰인다.

세 가지의 차이

1. 경로2. 내용3. 결재
보는 것주소, 목적지, 도구, 추론 제공자단어, 값, 문장, 출처검사 결과와 수정안
집행하는 곳기밀 영역은 샌드박스 프록시와 게이트웨이. 공개 영역은 샌드박스가 없고 코드가 부르는 곳이 정해져 있음코드 검사, 검열 에이전트결재 화면의 사람
성격기밀 영역은 강제. 공개 영역은 코드에 달림판단. 틀릴 수 있음최종 결정
목록이 바뀌는 빈도드묾결재할 때마다—
바꾸는 사람관리자결재자, 개인—

결정이 목록으로 쌓이는 방식

결정생기는 항목적용
거절차단 항목바로
수정 후 승인차단 항목과 대체 표현바로
승인허용 항목담당자가 확인한 뒤. 같은 문장, 같은 독자에게만

목록이 부딪힐 때

  1. 차단이 허용을 이긴다.
  2. 비밀값 패턴의 차단은 어떤 허용으로도 풀리지 않는다.
  3. 공식 기준이 개인 기준보다 앞선다. 개인 기준으로 더 조이는 것은 언제나 가능하다.
  4. 허용은 보류를 통과로 바꿀 수 있을 뿐, 차단을 바꾸지 못한다.
