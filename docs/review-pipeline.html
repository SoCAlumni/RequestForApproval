RFA 기밀 검토 흐름

기밀에 대한 판단은 기밀 영역을 떠나기 전에 끝낸다. 코드와 검열 에이전트가 먼저 거르고, 사람이 꼼꼼히 검사한다. 경계를 넘은 뒤에는 다듬기와 게시만 남는다. 사람의 결정은 목록으로 쌓여 다음 검사에 쓰인다.

세 가지의 차이

1. 경로2. 내용3. 결재
보는 것주소, 목적지, 도구, 추론 제공자단어, 값, 문장, 출처원문, 걸러낸 안, 걸린 사유
집행하는 곳기밀 영역은 샌드박스 프록시와 게이트웨이. 공개 영역은 샌드박스가 없고 코드가 부르는 곳이 정해져 있음코드 검사, 검열 에이전트기밀 검사 화면의 사람
도는 곳모든 단계기밀 영역 안경계를 넘기 직전
목록이 바뀌는 빈도드묾검사할 때마다—
바꾸는 사람관리자검사하는 사람, 개인—

결정이 목록으로 쌓이는 방식

기밀 검사에서의 결정생기는 항목적용
거절차단 항목바로
고쳐서 승인차단 항목과 대체 표현바로
승인허용 항목담당자가 확인한 뒤. 같은 문장, 같은 독자에게만

목록이 부딪힐 때

  1. 차단이 허용을 이긴다.
  2. 비밀값 패턴의 차단은 어떤 허용으로도 풀리지 않는다.
  3. 공식 기준이 개인 기준보다 앞선다. 개인 기준으로 더 조이는 것은 언제나 가능하다.
  4. 허용은 보류를 통과로 바꿀 수 있을 뿐, 차단을 바꾸지 못한다.
